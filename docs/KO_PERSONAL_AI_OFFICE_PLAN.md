# 나만의 픽셀 AI 오피스 — 개발 계획

> Pixel Agents 기반 개인용 한국어 AI 오피스. 최초 작성: 2026-11-02.

## 목표
- 위에서 내려다보는 귀여운 픽셀 아트 사무실
- 고정된 네 명의 AI 캐릭터: 재무, 일상, 업무, 건강
- 모든 메뉴와 상태 메시지 한국어 지원
- 대화 요약, 사용자 승인된 장기 기억, 업무별 기록을 다음 세션에서도 재활용
- Windows PC 및 브라우저에서 실행할 수 있는 개인용 앱

## 원본과의 차이
원본 Pixel Agents는 Claude Code 터미널 활동을 시각화합니다. 현재 원본만으로는 재무·일상·업무·건강 에이전트의 독립적인 개인 비서 기능이나 장기 기억이 자동 구현되지 않습니다. 이 프로젝트에서는 애니메이션 UI를 기반으로 별도의 대화·에이전트·저장 계층을 추가합니다.

## 단계별 구현
1. **기초 검증**: 원본 빌드, Windows 실행, 라이선스 확인.
2. **UI 한국어화**: 화면 문자열 분리, ko-KR 기본 언어, 영어 대체 표시.
3. **4인 캐릭터**: 네 역할을 고정 배치하고 상태·선택·대화 패널 추가. 캐릭터 에셋의 라이선스와 상표권을 검토하여 오리지널 귀여운 픽셀 캐릭터를 기본 사용.
4. **기억 계층**: SQLite 기반 로컬 저장, 역할별 분리, 전역 공통 기억, 검색, 수정·삭제·내보내기. 민감한 데이터는 사용자 동의 후에만 저장.
5. **AI 연결**: 제공자 교체 가능한 어댑터; 사용자 API 키는 소스 코드/GitHub에 커밋하지 않기.
6. **안정화**: 테스트, 자동 빌드, 배포 가이드.

## 데이터 구조 초안
- agents: id, role, display_name, avatar, status
- conversations: id, agent_id, created_at
- messages: id, conversation_id, role, content, created_at
- memories: id, scope, category, content, source, updated_at, consent
- tasks: id, agent_id, title, status, updated_at

## 보안 원칙
- 실명, 의료 정보, 금융계좌, 업무상 고객 정보 등을 공개 저장소에 올리지 않음
- 기본 설정은 로컬 우선; 기억 접근 및 삭제를 사용자가 통제
- 외부 시스템으로의 전송과 자동 실행은 별도 권한 요구
